# DPI Override

A small Windows tool for setting the **"Override high DPI scaling behavior"** compatibility
option for programs, for **all users**, without clicking through each program's
Properties → Compatibility dialog.

- Lists running programs plus every program that already has a DPI override
- Shows the current setting for all users and for the current user
- Sets *Application*, *System*, *System (Enhanced)* or removes the override
- Keeps any other compatibility flags (e.g. Windows 7 mode, run as admin) untouched
- **Rendering column:** shows how each running program is actually scaled right now
  (Sharp, Main screen only, Blurry, GDI-scaled), with a "Possibly blurry" filter. Programs running
  without a visible window (background helpers, services) show "No window" and aren't counted as blurry
- **Restart:** closes and reopens selected programs with their original arguments so a new
  setting takes effect (non-elevated programs are restarted non-elevated)
- **Groups:** programs from the same install folder (e.g. `C:\Riot Games\League of Legends`) are
  shown as one expandable row named after the program's folder (version and `bin`/`app` folders are
  skipped, so `...\Discord\app-1.0.9262` shows as "Discord"); selecting the row applies the setting to all of them. Click the
  arrow, double-click, or use ←/→ to open and close a group
- **Whole folders:** *Add → All programs in a folder…* adds every .exe in a folder and its
  subfolders as one group, ready to apply. With a program selected, the menu also offers its folder

The setting is stored in
`HKLM\SOFTWARE\Microsoft\Windows NT\CurrentVersion\AppCompatFlags\Layers`
(value name = full .exe path, e.g. `~ HIGHDPIAWARE`), so the tool asks for admin rights.

## Requirements

Windows 10 or 11. It runs on the .NET Framework 4.x that ships with Windows, nothing to install.

## Building

**On Windows:** run `build.cmd` (uses the C# compiler included with Windows).

**On Linux:** install Mono (`mono-mcs`, `libmono-system-windows-forms4.0-cil`) and run `./build.sh`.

The output is `bin/DpiOverride.exe`.

> The code targets C# 5 and .NET Framework 4.x APIs only. Mono's class library has some
> newer overloads (e.g. `string.TrimEnd(char)`) that compile fine but crash on Windows,
> so check the framework version of any new API you use.

## Project layout

| Path | What |
|---|---|
| `src/Core.cs` | Registry logic, process list, entry point, logging |
| `src/Ui.cs` | Material-style WinForms UI (owner-drawn controls) |
| `src/Native.cs` | Win32 helpers: DPI awareness of processes, restarting programs |
| `assets/` | App icon and logo (generated by `tools/make_icon.py`) |
| `tools/seed_test_registry.cs` | Sample data for testing the UI under Mono on Linux |

`DpiOverride.exe --selftest` runs the flag-rewriting and folder-grouping unit checks.
`DpiOverride.exe --demo` shows fake running programs (used to test the UI under Mono on Linux).
`DpiOverride.exe "<program.exe, shortcut or folder>"` opens with that program, or every program in that folder, added and selected.
When DPI Override is already open, a second launch hands its paths to that window and brings it to the front instead
of opening another window (and another UAC prompt).

**Explorer entry:** ⋯ → *Add "DPI scaling…" to Explorer* adds that item to the right-click menu of every program
and shortcut, for all users. It opens DPI Override with that program added and selected. On Windows 11 it's under
*Show more options* (only packaged apps can add to the new compact menu). The entry follows the tool if its
.exe is moved, and the same menu item removes it again.

**Undo:** every change (Apply, Off, Remove override, Restore from backup) can be undone with UNDO in the
message that follows it, Ctrl+Z, or ⋯ → Undo. It puts back the exact previous values, other compatibility flags
included, for the last 20 changes while the app is open.

**Back up and restore** (⋯ menu in the title bar): *Back up overrides…* saves every DPI override (all users and
current user) as a `.reg` file, which can also be restored by double-clicking it. *Restore from backup…* reads only the
DPI override keys from such a file and sets each program's DPI mode as in the backup; other compatibility flags,
and programs that aren't in the backup, stay as they are.

Programs, shortcuts (.lnk) and folders can also be dropped onto the window. A shortcut to a Squirrel launcher
(Discord, Slack, …) adds the real program from the newest `app-<version>` folder. Because the tool runs as
administrator, it accepts drops through `WM_DROPFILES` (Windows blocks normal drag and drop from Explorer into
elevated windows).
